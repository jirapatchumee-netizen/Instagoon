# Qwen 2.1 T2I — ยุติการใช้งานแล้ว

วันที่ 26 ตุลาคม 2026 เจ้าของให้ cleanup เพื่อคืนพื้นที่ และแจ้งข้อจำกัด commercial license เป็นเหตุผลของการยุติใช้งาน

ลบ weights Qwen 3 ไฟล์ ถอน profile ที่เปิดใช้ render_image และลบ scratch ComfyUI ที่ซ้ำกันแล้ว พื้นที่ว่างเพิ่มที่ตรวจได้ประมาณ 32.70 GB เก็บ framework, ComfyUI หลัก และ Python environment ไว้สำหรับงานต่อไป

เอกสารแผน Qwen, workflow และภาพใน art/outputs เป็นประวัติการทดลอง ไม่ใช่ pipeline ที่พร้อมใช้งาน และไม่ใช่การอนุมัติให้นำภาพไปใช้เชิงพาณิชย์ แผนถัดไปของเจ้าของคือ Z-Image-Turbo; ยังไม่ได้ติดตั้งหรือสร้าง preset ใหม่
