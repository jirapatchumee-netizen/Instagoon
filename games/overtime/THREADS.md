| :--- | :--- | :--- | :---: |
| **LV.1 GUEST Keycard** | ได้รับตั้งแต่เริ่มเกมในห้องเซิร์ฟเวอร์ | ชั้น 2 (แผนกการตลาด) | ✅ ครอบครองแล้ว |
| **น้องเนย ID Card Scan** | ชิงจากกระเป๋าสตางค์ใต้โต๊ะทำงาน (Stage 1) | ปลดล็อก Terminal น้องเนย | 🔄 รอประมวลผล |

| **CCTV & Audit Bypass Pass** | ได้รับหลังเคลียร์ด่านคุณรินดา (Stage 3) | ปิดสัญญาณเตือนภัย & ชั้น 19 | ⏳ ยังไม่ปลดล็อก |

## 📊 3. เมทริกซ์ตัวแปรหลัก (Variables State Table)

| ตัวแปร | ผลกระทบต่อโครงเรื่อง | กฎเกณฑ์และขีดจำกัด |
| :--- | :--- | :--- |
| `suspicion` | ความระแวงของคนรอบตัว | • $+15\%$ ถึง $+35\%$ เมื่อเลือกคำตอบลุกลี้ลุกลน<br>• $-10\%$ เมื่อใช้ทักษะ IT ช่วยเหลืออย่างแนบเนียน<br>• **$\ge 100\%$ = BAD END ทันที** |
| `noeyAffection` | ความไว้วางใจของน้องเนย | • $\ge 7$: ยอมบอกเรื่องที่ซ่อนสำเนาบัตรคุณพิมพ์ในฝ่าย HR |
| `scannedCards` | ตัวนับจำนวนบัตร ปชช. ในระบบ | • สะสมครบ 5 ใบ เพื่อเข้าเงื่อนไข True / Spicy End |
| `unlockedPhotos` | แกลเลอรีภาพ Portrait ลับ | • สะสมครบทุกใบเพื่อปลดล็อก Achievement ลับ |

## ⚡ 4. ห่วงโซ่เหตุการณ์ข้ามด่าน (Cross-Stage Dependencies)

- **Chain 1:** ต้องผ่าน Stage 1 น้องเนย $\rightarrow$ จึงจะทราบว่าเครื่องสแกนเอกสารที่ฝ่าย HR มักกระดาษติดบ่อยๆ
- **Chain 2:** ต้องผ่าน Stage 2 คุณพิมพ์ $\rightarrow$ คุณพิมพ์จึงจะยอมโทรศัพท์เรียกคุณรินดาออกจากห้องเพื่อเปิดช่องว่างให้อาร์มเข้าไปสำรวจ
- **Chain 3:** ต้องผ่าน Stage 3 คุณรินดา $\rightarrow$ เพื่อปิดสัญญาณเตือนภัยลิฟต์ชั้น 19 มิฉะนั้นคุณมีนาจะสังเกตเห็น
- **Chain 4:** ต้องผ่าน Stage 4 คุณมีนา $\rightarrow$ เพื่อทราบเวลากินกาแฟและตารางเดินตรวจตึกกะดึกของคุณหนูเร-อา
