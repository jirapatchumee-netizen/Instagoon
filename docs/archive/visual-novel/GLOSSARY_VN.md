# 📖 Glossary — Frost Novel Platform & Overtime Secrets (Archived)

## 🌐 1. แพลตฟอร์มและสตูดิโอสร้างเกม (Platform & Creator Studio Domain)

**Game Project (โปรเจกต์เกม)**:
ผลงานเกม Visual Novel หนึ่งเรื่องบนแพลตฟอร์ม ประกอบด้วยข้อมูลหลักของเกม, คลังทรัพยากร, ตัวแปรเริ่มต้น, และชุดของฉากทั้งหมด
_Avoid_: Story File, App, Package

**Asset Registry (คลังทรัพยากรเกม)**:
ศูนย์รวมข้อมูลตัวละคร (พร้อมชุดสีหน้า), ภาพฉากหลัง, ไฟล์เสียง, และตัวแปรทั้งหมดที่ประกาศไว้ในโปรเจกต์เกม เพื่อให้โหนดต่างๆ อ้างอิงด้วยรหัส
_Avoid_: Media Folder, Hardcoded Assets

**Scene Map (แผนผังระดับฉาก)**:
มุมมองภาพรวมระดับบนสุดของสตูดิโอที่แสดงความเชื่อมโยงระหว่างฉากทั้งหมดในโปรเจกต์เกม
_Avoid_: World Map, Global Canvas

**Scene Canvas (กระดานเวิร์กโฟลว์รายฉาก)**:
พื้นที่ทำงานแบบกราฟโหนด (Node Workflow) สำหรับออกแบบลำดับการดำเนินเรื่องและตรรกะภายในฉากเดียว
_Avoid_: Node List, Script Editor

**Beat Node (โหนดจังหวะดำเนินเรื่อง)**:
บล็อกหน่วยย่อยบนกระดานเวิร์กโฟลว์ที่รวมบทสนทนา, ผู้พูด, การจัดวางตัวละครบนเวที, และฉากหลังเข้าไว้ในจังหวะเดียว
_Avoid_: Raw Text Line, Atomic Sprite Node

**Port (จุดเชื่อมต่อสาย)**:
จุดรับข้อมูลเข้า (Input Port) และจุดส่งต่อไปยังโหนดถัดไป (Output Port) บนขอบของโหนด โดยโหนดทางเลือกและโหนดเงื่อนไขจะมีจุดส่งออกแยกตามแต่ละเส้นทาง
_Avoid_: Link Dropdown, Next ID Field

**Execution Trace (การติดตามการรันบนกราฟ)**:
การไฮไลต์โหนดและเส้นเชื่อมที่กำลังทำงานอยู่บนกระดานเวิร์กโฟลว์แบบเรียลไทม์ พร้อมแสดงค่าตัวแปรปัจจุบันขณะผู้สร้างกดทดสอบเล่นจากโหนดใดๆ
_Avoid_: Console Log, Blind Playtest

## 🛒 2. ร้านค้า ชุมชน และการแบ่งปันสิทธิ์ (Storefront, Social & Sharing Domain)

**Episode (ตอนวางจำหน่าย)**:
หน่วยของการแบ่งบทเนื้อเรื่องเพื่อเปิดให้เล่นฟรีหรือจำหน่าย ซึ่งจับคู่แบบหนึ่งต่อหนึ่งกับหนึ่งด่าน (Stage) ของเกม และประกอบด้วยหลายฉากย่อย (Scenes)
_Avoid_: Micro-Scene Purchase, Chapter File

**Full-Bundle Ownership (สิทธิ์เจ้าของฉบับสมบูรณ์)**:
สถานะของผู้เล่นที่ซื้อหรือปลดล็อกเกม Visual Novel ครบทุกตอนแล้ว ซึ่งเป็นเงื่อนไขเดียวในการได้รับโควตาแบ่งปันเกมให้เพื่อน
_Avoid_: Partial Purchase, VIP Account

**Friend Pass Slot (สล็อตแบ่งปันเกมให้เพื่อน)**:
โควตาสิทธิ์ให้ยืมเล่นฟรีจำนวนสูงสุด 3 สล็อตต่อเกม สำหรับผู้ที่มีสิทธิ์เจ้าของฉบับสมบูรณ์ โดยเพื่อนที่ได้รับสล็อตจะเข้าเล่นได้ทุกตอนและมีข้อมูลเซฟเกมแยกเป็นอิสระจากเจ้าของสิทธิ์
_Avoid_: Account Sharing, Free Gift Copy

**Steam-Style Verdict (คำตัดสินรีวิวเกม)**:
การประเมินผลรีวิวแบบสองขั้ว (แนะนำ 👍 หรือ ไม่แนะนำ 👎) ร่วมกับคะแนนดาว เพื่อคำนวณระดับความนิยมรวมของเกม พร้อมแสดงป้ายเวลาเล่นและสถานะการเป็นเจ้าของหรือการรับสิทธิ์จากเพื่อน
_Avoid_: Anonymous Comment, Simple Star Rating

**Game Share Card (การ์ดเชิญรับสิทธิ์เล่นเกม)**:
ข้อความพิเศษแบบโต้ตอบได้ในห้องแชทเพื่อนหรือแชทกลุ่ม ที่เจ้าของสิทธิ์ส่งให้เพื่อนกดรับสล็อตแบ่งปันเกมและเริ่มเล่นได้ทันทีจากหน้าแชท
_Avoid_: Plain URL Link

## 🏢 3. โครงสร้างเรื่องและระบบเกม (Narrative & Game Hierarchy)

| คำศัพท์ | คำจำกัดความ (Definition) | ตัวอย่างในระบบ |
| :--- | :--- | :--- |
| **Stage (ด่าน)** | ลำดับขั้นของเป้าหมายหลักตามชั้นอาคาร (มีทั้งหมด 5 Stages) แต่ละ Stage มีเป้าหมายเป็นสาวสวย 1 คน | Stage 1 (น้องเนย ชั้น 2) ➔ Stage 5 (คุณหนู เร-อา ชั้น 20) |
| **Scene (ฉาก)** | เหตุการณ์ย่อยใน 1 ตอน เก็บแยกเป็น 1 ไฟล์ JSON มีจำนวน Node ประมาณ 10–25 โหนด | `S1_01_server_room`, `S1_02_noey_desk` |
| **Node (จุดดำเนินเรื่อง)** | หน่วยย่อยที่สุดของบทสนทนา, ทางเลือก, การเปลี่ยนตัวแปร, หรือฉากจบ | `010`, `020`, `060` |
| **Checkpoint (จุดเริ่มใหม่)** | จุดย้อนกลับที่เซฟไว้ล่วงหน้าก่อนเกิดเหตุการณ์เสี่ยงภัย เพื่อให้ผู้เล่นกดย้อนกลับมาลองใหม่ได้ทันทีเมื่อพบ Bad End | `retryNodeId: "040"` |
