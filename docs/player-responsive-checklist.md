# ตรวจ Responsive ของ Player

เริ่มแอปด้วย `pnpm dev --host 127.0.0.1` แล้วเปิด URL ใน Safari ของ iPhone Simulator หรือในเบราว์เซอร์สำหรับเดสก์ท็อป

## หน้าจอที่ตรวจ

- iPhone SE แนวตั้ง และ iPhone 16 แนวตั้งใน Safari
- iPhone 16 แนวนอนใน Safari
- เดสก์ท็อปขนาด 1280 × 800
- iPhone จริงอย่างน้อยหนึ่งเครื่อง หากมีเครื่องสำหรับทดสอบ

## ขั้นตอน

1. เข้า Player และเดินเรื่องจนถึงตัวเลือกที่มีข้อความยาว ตรวจว่าอ่านและแตะได้ครบ
2. เปิดเมนูแล้วตรวจ Back, Auto, Skip, Log และ Config ปิดแต่ละหน้าต่างแล้วกลับไปเล่นต่อ
3. บันทึกลงสล็อตทดสอบที่ว่าง เดินเรื่องต่อ แล้วโหลดสล็อตนั้น ตรวจว่ากลับมาที่จุดเดิม
4. หมุนมือถือเป็นแนวนอน ตรวจข้อความขอให้หมุนและปุ่มเล่นต่อ ตรวจว่า Auto และ Skip หยุด แล้วเลือกเล่นต่อ ปัดตัวเลือกจนถึงข้อสุดท้ายโดยไม่เลือกคำตอบโดยไม่ได้ตั้งใจ
5. ขยายข้อความหรือซูม แล้วตรวจว่าบทสนนทนา ตัวเลือก และปุ่มปิดยังใช้งานได้
6. บนมือถือจริง ตรวจตำแหน่งแถบ Safari และการแตะขณะถือเครื่อง

ห้ามใช้สล็อตที่มีข้อมูลสำคัญในการทดสอบบันทึกหรือโหลด
